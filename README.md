# Webingo

Generate shareable bingo cards from any word list. No account, no server — the entire card lives in the URL.

**[Open the generator →](https://gavinhaggis.github.io/webingo/)**

---

## How it works

1. **Paste your items** — CSV, TSV, or one per line. Or load one of the built-in presets.
2. **Configure** — 3×3, 4×4, or 5×5 grid. Optional free space. Win condition from first line to full blackout.
3. **Generate** — get N unique shareable links, one per player. Each card gets a different shuffle.
4. **Play** — open a card link, click cells as you spot items. Win detection is automatic.
5. **Host** — one host URL lets the organiser see all cards side by side.

---

## Features

- **URL-encoded cards** — the card is the link. No database, no expiry, works forever.
- **Unique per-player cards** — each link is a different subset and shuffle of your items.
- **Configurable win conditions** — first line, N lines, or full blackout.
- **Click state saved locally** — refresh the page and your marks are still there.
- **Win image export** — canvas-rendered PNG with player name, card seed, and UTC timestamp. No external library.
- **Host view** — one URL to distribute and preview all cards at once.
- **6 built-in presets**, unlimited custom lists.

## Self-hosting

```bash
git clone https://github.com/gavinhaggis/webingo.git
cd webingo
open index.html   # no server needed
```

To deploy your own instance on GitHub Pages:

1. Fork this repo
2. Go to **Settings → Pages → Source**: `main` branch, root `/`
3. Your generator is live at `https://<username>.github.io/webingo/`

Card links generated by your instance will point to your domain automatically.

## Adding a preset

In `index.html`, add your items to the `PRESETS` object and a matching `<option>` to the dropdown:

```js
// PRESETS object (~line 305)
mypreset: ["item one", "item two", "item three", "..."],
```

```html
<!-- <select id="preset-select"> -->
<option value="mypreset">My Preset Name</option>
```

Then add a matching entry to `PRESETS_META` in `demo.html` to include it in the landing page showcase.

## Tech

| Concern | Approach |
|---|---|
| Compression | [lz-string](https://github.com/pieroxy/lz-string) via jsDelivr CDN |
| Unique IDs | Inline nanoid (8-char alphanumeric, no dependency) |
| Canvas export | Native browser Canvas API |
| Styling | Vanilla CSS with custom properties |
| Framework | None — plain HTML / CSS / JS |

> **Encoding note:** payloads use `LZString.compressToBase64()` + URL-safe base64. A common mistake is using `btoa(LZString.compress(...))` — this throws `InvalidCharacterError` because `LZString.compress()` outputs characters outside Latin-1. See `CLAUDE.md` for the full explanation.
